What these do

  • Reject keeps the drawing in the artist's gallery, excludes it from export, and still counts toward the picker — so rejecting is not a way to get the same Pokémon dealt again.
  • Delete hides it from the artist, excludes it from export, and releases the Pokémon back to the picker. The file may stay on disk and its drawing number is never reused.
  • Unapprove and Delete retire the question's uniqueId permanently. Approving the same drawing again creates a new question with a new number — it is not a reversible toggle.
